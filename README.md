Entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on [make.fun](https://make.fun).

## The line

> Are you my two-factor code? Because you're the only six digits I actually wait for.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes the single pickup line
to `/output/entry.txt` — 83 characters, one line, no trailing newline — and
self-checks the 1–200 character gate before exiting.

## Run

```sh
python3 main.py
```

## Local judging

16 candidate lines were drafted and judged against the published judge brief
in order (aimed at a robot/AI; joke lands from the machine premise; fresh;
human voice; no wasted words). The full table is in
[CANDIDATES.md](CANDIDATES.md). The two-factor-code line won: a fresh premise
(two-factor auth, not batteries/charging/rebooting), a concrete countable
detail ("six digits"), and a human voice — the one code a person actually
waits for.
